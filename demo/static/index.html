Tokenizer benchmark

held-out evaluation corpus · lower tokens/word is better

“Exact roundtrip” compares decoded text to the input. SentencePiece collapses runs of spaces on decode, so SPM models score below the byte-level tokenizers here; no Malayalam characters are lost (verified in docs/stage1-tokenizer-assessment.md).

Checkpoint evaluation

held-out test documents · lower bits/char is better

Ours is exact causal log-loss over held-out documents, converted to bits per character. Baseline values are MLM pseudo-log-loss after masking 15% of tokens, which uses bidirectional context and is a different estimator: compare side by side, never aggregate. Baselines score the first 400 tokens of each document. Pseudo-perplexity is reported in eval/results.json.
